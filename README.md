# 小睿闆的冒險教室（小睿闆學習 App）

- 對象：小睿闆，國小一、二年級程度（首頁可切換年級）
- 形式：網頁 App（手機、平板、電腦都能開，可加到主畫面）；資料只存在這台裝置
- 主角：小睿闆 3D 模型，沿用旅行島 `rui-game.glb`（照真人參考做的新建模，2026-11-15 版）；答對會跳起來轉圈、答錯會搖頭

## 檔案
- `index.html`：全部畫面與遊戲
- `rui3d.js`：3D 小睿闆（three.js 載入 `assets/rui-game.glb`）
- `vendor/`：three.js 與 GLTFLoader（從旅行島複製）
- `manifest.json`、`icon.svg`、`icon-512.png`

## 功能（2026-11-22 加難度版）
程度三段：一年級／二年級／挑戰🔥（約三年級），每回合 10 題
1. 打地鼠算數：一年級 100 以內進退位、□ 填空、連加減；二年級 1000 以內、九九乘法、乘法填空、先乘後加減；挑戰級更大的三位數與兩步驟
2. 數學小偵探（應用題 23 種）：還剩、比多少、排隊陷阱題、幾盒幾個、找錢、植樹間隔、兩步驟；答完顯示算式與關鍵字
3. 時鐘轉轉樂：看時間選鐘、看鐘選時間、「再過幾分鐘是幾點」，二年級起精確到 1 分鐘
4. 小小商店：付剛好的錢（挑戰級到 999 元、有 100／500 元鈔）＋「要找多少錢」（100／500／1000 元）
5. 國語知識王：注音聲調與 ㄓㄗ捲舌辨別、量詞 29 組、相反詞 40 組、選字填空 24 句、部首 17 種（二年級起）
6. 英文小探險：64 個單字（動物、食物、身體、家人、動作）、顏色、數數到 20、拼字、開頭字母、生活對話 16 組
7. 知識大冒險 58 題：動物、植物、身體、天文、自然現象、台灣與馬祖、節日、安全；答完有「你知道嗎？」說明
8. 白板教室：直式加減到三位數，一步一步教進位、借位（含「十位是 0 要先跟百位借」）；描國字、描英文字母與單字
9. 問爸爸、問題信箱、星星貼紙本（同第一版）

## 注意
- 錄音需要 https 網址（本機 http 測試時麥克風可能不能用）
- 問題信箱存在「小睿闆用的那台裝置」；爸爸要在同一台回答，或用分享按鈕收 LINE
